
# Laurus Studio - Week 2 Layout

## Project Overview

This is my Week 2 Assignment 2 project for WDD 325 at Laurus College. I created a multi-page website using Next.js and Tailwind CSS, based on my Week 2 Figma design.

## Pages

- Home: Displays the main Home Page heading.
- About: Introduces Laurus Studio and its website design services.
- Contact: Provides information about contacting Laurus Studio.

## Layout Approach

I used the Next.js App Router to create separate Home, About, and Contact pages.

I created reusable Header and Footer components in the components folder. Both are included in app/layout.js so they appear consistently on every page.

The Header includes navigation links that allow visitors to move between the three pages.

## Design Choices

I followed my Figma design by using a white background, dark text, navy-blue Header and Footer, and centered page headings.

I used Tailwind CSS for spacing, typography, alignment, and responsive layout styling.

## Development and Deployment

I built and tested the website locally using Visual Studio Code and the Next.js development server.

The completed project is stored on GitHub and deployed using Vercel.

Start the development server:

npm run dev

Open http://localhost:3000 in a browser.
